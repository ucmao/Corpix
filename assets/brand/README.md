# Corpix 企业数据标志

基于项目“多平台企业信息查询与标准化引擎”的定位，由内置 image_gen 工具重新生成。

公文包轮廓表达企业，三条蓝色信息流汇聚到一个橙色方块，表达多平台来源归一为企业档案。保留深蓝、亮蓝、珊瑚橙及圆润粗描边风格，减少建筑插画细节。背景透明。

- `corpix-logo.png`：生成母版。
- `icon-512.png`、`icon-192.png`：应用图标。
- `apple-touch-icon.png`：180 像素。
- `favicon-16x16.png`、`favicon-32x32.png`、`favicon-48x48.png`：浏览器图标。
- `favicon.ico`：16、32、48 像素组合。
- `icon-prompt.txt`：完整生图提示词。

此目录保存新设计及配套尺寸，项目 README 仍保留原图，尚未切换。
