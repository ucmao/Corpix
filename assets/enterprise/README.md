# 企业楼群图标方案

以三栋正面办公楼表达企业，采用深蓝描边、亮蓝楼体、白色窗格和珊瑚橙楼顶；小放大镜表达查询。透明背景，无文字。

由内置 image_gen 工具生成，提示词保存在 `icon-prompt.txt`。本目录为新版候选，尚未替换项目 README 中的图标。

- `corpix-logo.png`：生图母版。
- `icon-512.png`、`icon-192.png`：应用图标。
- `apple-touch-icon.png`：180 像素图标。
- `favicon-16x16.png`、`favicon-32x32.png`、`favicon-48x48.png`：浏览器图标。
- `favicon.ico`：包含上述三个 favicon 尺寸。
